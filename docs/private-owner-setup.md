# إعداد كلمة مرور المالك محليًا دون مشاركة الأسرار

الأداة المحلية: `scripts/setup-owner-secrets.mjs`. لا تستورد التطبيق أو SDK، ولا تقرأ بيانات بيئتك أو تتصل بالشبكة أو بقاعدة بيانات. لا ترسل كلمة المرور إلى Codex أو ChatGPT أو GitHub أو أي موقع توليد تجزئات. لا تحفظ كلمة المرور نفسها في ملف.

## صيغة التحقق الفعلية

المصدر: `passwordMatches` في `app/lib/private/crypto.ts` و`getConfig` في `app/lib/private/config.ts`.

```text
scrypt$32768$8$1$<salt:64 hex characters>$<derived key:128 hex characters>
```

- خوارزمية scrypt: `N=32768`, `r=8`, `p=1`، مفتاح مشتق بطول 64 بايت، `maxmem=67108864` بايت.
- salt عشوائي من 32 بايت، بترميز hexadecimal (64 حرفًا).
- المفتاح المشتق بترميز hexadecimal (128 حرفًا)، وليس base64 أو bcrypt أو Argon2.
- كلمة المرور تُشفّر إلى UTF-8 قبل الاشتقاق. لا قصّ للمسافات أو تغيير للعربية أو تطبيع Unicode؛ أدخلها لاحقًا بالطريقة نفسها.
- التحقق يستخدم `timingSafeEqual`. يقبل المدقق نمط hex بالأحرف الكبيرة أو الصغيرة؛ الأداة تكتب lowercase.
- الأداة تطلب 16–128 وحدة UTF-16 (طول JavaScript، متوافق مع حد حقل الدخول)، وبحد أقصى 512 بايت UTF-8، مع تأكيد كلمة المرور. بعض الرموز مثل emoji تُحسب وحدتين.

## تشغيل الأداة على جهازك فقط

1. استخدم جهازك الموثوق وطرفية محلية خاصة غير مسجلة، دون مشاركة شاشة أو session recording. لا تشغّلها داخل Codex أو GitHub Actions أو طرفية سحابية أو خدمة عامة.
2. يلزم Node.js 24. لا تحتاج الأداة `npm install` أو شبكة. على macOS/Linux استخدم طرفيتك المحلية. على Windows استخدم WSL محليًا ومسار home الخاص بلينكس؛ الأداة ترفض Windows الأصلي لأن Unix modes لا تضمن Windows ACL.
3. من نسخة المستودع التي تحتوي الأداة شغّل:

   ```sh
   node scripts/setup-owner-secrets.mjs
   ```

4. اختر كلمة مرورك وأدخلها ثم أكّدها. الإدخال مخفي دون نجوم. لا تضعها في وسيطة أمر، أو متغير shell، أو ملف داخل المستودع، أو محادثة. Ctrl+C يلغي العملية.
5. لا تظهر كلمة المرور أو التجزئة أو المفاتيح. يظهر **مسار مجلد فقط** داخل home، باسم `.madar-owner-secrets-…`. يُنشأ مجلد جديد في كل تشغيل، بصلاحيات `700`، وثلاثة ملفات `600` دون استبدال ملفات موجودة:

   على macOS يكون المسار عادةً `/Users/<اسمك>/.madar-owner-secrets-<لاحقة عشوائية>/`. تتحقق الأداة من المسارات الفعلية بعد حل الروابط الرمزية، وترفض التشغيل إذا كان home داخل مستودع الأداة، قبل طلب كلمة المرور أو توليد القيم.

   | اسم الملف / متغير Vercel | المحتوى |
   |---|---|
   | `MADAR_OWNER_PASSWORD_HASH` | تجزئة scrypt الكاملة؛ ليست كلمة المرور الصريحة |
   | `MADAR_SESSION_SECRET` | 32 بايت عشوائية مستقلة من `crypto.randomBytes`، ممثلة بـ64 حرف hex |
   | `MADAR_STORE_ENCRYPTION_KEY` | 32 بايت عشوائية مستقلة أخرى من `crypto.randomBytes`، ممثلة بـ64 حرف hex |

الـsalt يستخدم استدعاء عشوائي مستقل أيضًا. لا إعادة استعمال للمفتاح بين الوظائف. لا تستخدم قيم الاختبارات أو كلمات الأمثلة كأسرارك.

**ترميز سر الجلسة:** الكود يقبل نصًا بطول 64 حرفًا على الأقل؛ اختيار hex هنا توصية من الأداة وليس شرطًا عامًا في المدقق. تستخدم JWT نص الـhex نفسه كـUTF-8، ولا تفك ترميزه قبل إدخاله في Vercel.

**ترميز مفتاح التخزين:** hex من 64 حرفًا بالضبط شرط إلزامي؛ يفك الخادم ترميزه إلى 32 بايت لتشفير AES-256-GCM. لا تضع base64 أو كلمة مرور أو تجزئة أخرى مكانه.

الأداة القديمة `npm run notion:password` تخفي الإدخال لكنها تطبع التجزئة. استخدم الأداة الجديدة إذا أردت عدم إظهار القيم في الطرفية. لم يتغير منطق المصادقة أو الأمر القديم.

### تنزيل الأداة على macOS

من Terminal محلية، في مجلد عادي مثل `~/Projects` خارج iCloud Drive، احصل على الفرع:

```sh
git clone --branch feature/private-owner-setup --single-branch https://github.com/Elhamown/life-os.git
cd life-os
node --version
node scripts/setup-owner-secrets.mjs
```

تأكد أن إصدار Node يبدأ بـ `v24.`. أمر Git ينقل الكود فقط؛ نفّذه قبل إدخال أي كلمة مرور. لا حاجة لتشغيل الموقع أو `npm install` أو نشره. إذا لديك نسخة بالفعل استخدم `git fetch origin` ثم `git switch feature/private-owner-setup` مع الحفاظ على أي تعديلات محلية.

## نقل القيم دون عرضها

انسخ كل ملف مباشرة للحافظة، ثم ألصقه في حقل البيئة الخاص؛ لا تستخدم `cat` أو `echo`. في الأوامر التالية استبدل `/absolute/private/directory` بالمسار الذي ظهر، وليس بقيمة سرية.

macOS:

```sh
pbcopy < /absolute/private/directory/MADAR_OWNER_PASSWORD_HASH
```

Linux مع Wayland (إذا كانت أداة wl-copy مثبتة):

```sh
wl-copy < /absolute/private/directory/MADAR_OWNER_PASSWORD_HASH
```

غيّر اسم الملف إلى `MADAR_SESSION_SECRET` ثم `MADAR_STORE_ENCRYPTION_KEY` لكل عملية نسخ. لا تستخدم مدير حافظة يزامن القيم سحابيًا؛ امسح الحافظة بعد الانتهاء. يمكنك نقلها إلى مدير أسرار محلي موثوق دون عرض القيم. لا تضع الملفات في Git أو مجلد تتم مزامنته إلى خدمة عامة.

## إضافتها إلى Vercel

توليد القيم محلي بالكامل. نشر التطبيق يحتاج إرسال **التجزئة والمفاتيح** إلى مخزن بيئة Vercel الخاص؛ كلمة المرور المختارة نفسها لا تُرسل أثناء التوليد. عند تسجيل الدخول لاحقًا تُرسل كلمة المرور عبر HTTPS إلى تطبيقك المنشور على Vercel للتحقق منها. هذا مختلف عن استخدام موقع طرف ثالث لتوليد تجزئة.

1. مشروع MADAR → Settings → Environment Variables.
2. أضف المتغيرات الثلاثة بأسمائها الدقيقة، والقيم فقط، دون اقتباسات أو `NAME=` أو مسافات إضافية. لا تستخدم `NEXT_PUBLIC_`.
3. اختر Preview والفرع الصحيح. استخدم مجموعة مستقلة للإنتاج. لا تغيّر مفتاح تشفير بيئة قائمة لمجرد إعادة تشغيل الأداة؛ احتفظ بمفتاح القاعدة القديمة ونسخة احتياطية آمنة منه.
4. يلزم أيضًا `MADAR_APP_ORIGIN`: أصل HTTPS الثابت الذي ستفتح منه الموقع، دون مسار أو شرطة مائلة أخيرة؛ و`DATABASE_URL`: اتصال PostgreSQL خاص مع إعداد TLS الموصى به من المزوّد وجداول MADAR المهيأة. الأداة لا تولّد اتصال قاعدة ولا تغيّرها.
5. احفظ المتغيرات، ثم أعد نشر Preview الصحيح بنفسك بعد اعتماد الإعداد. النشر القديم لا يلتقط المتغيرات الجديدة تلقائيًا. هذه الأداة لا تنشر أي شيء.

احفظ الأسرار في مكان خاص موثوق قبل إزالة الملفات المؤقتة محليًا. فقدان مفتاح التخزين قد يمنع استرداد البيانات المشفرة؛ تغييره يحتاج خطة إعادة تشفير منفصلة. تغيير تجزئة المالك أو سر توقيع الجلسة يبطل الجلسات السابقة.

## اختبار دون كشف أسرار

نافذة خاصة → العنوان المطابق للأصل → `/login` → كلمة مرورك الأصلية → الوصول إلى لوحة التحكم → تسجيل الخروج → التأكد من طلب الدخول مجددًا. لا تشارك HAR أو bodies الطلبات أو قيم Cookies؛ قد تتضمن كلمة المرور أو الجلسة. لا تحتاج أي تكامل Notion لهذا الاختبار.

اختبارات الأداة تستخدم كلمة مرور اصطناعية وعشوائية **ثابتة محقونة للاختبار فقط**؛ تتحقق من مطابقة مدقق المصادقة الحقيقي والترميزات ورفض الإدخال غير التفاعلي، دون إنشاء أسرار حقيقية أو تشغيل تكاملات.
