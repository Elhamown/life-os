# تصميم مدار والخطوط الأصلية

هذا الفرع يبني على `feature/single-owner-boundaries`؛ لا مشروع ثانٍ، ولا تغيير في منطق المزامنة. الأقسام السبعة حسب الطلب الأخير: اليوم، المساحات، التقويم، المساعد، اكتشاف Notion، مركز المزامنة، الإعدادات. على الجوال أربع وجهات وزر «المزيد» للأقسام الأخرى. الشاشات الداخلية قابلة لإعادة الفتح عبر `/?view=calendar` أو `settings` أو `spaces` أو `assistant`، وتبقى تحت حارس حساب المالك في `/`.

## ما يعمل

- الوضع الفاتح والداكن، البحث، الالتقاط من كل الأقسام، الالتقاط النصي المباشر، إكمال المهام، تحويل الملاحظات بنفس الهوية، ومراجعة الاقتراحات.
- التقويم اليومي والأسبوعي يعرض سجلات المهام والمواعيد التجريبية نفسها، مع تصفية المساحات واختيار اليوم. لا اختراع وقت للمهمة، ولا حفظ خارجي.
- المساحات الثماني وتبويباتها الخمسة وألوانها ومؤشرات المهام. إعدادات المظهر، حالة الخط والخصوصية وحساب المالك الواحد.
- معاينة اكتشاف اصطناعية واضحة التسمية دون اتصال أو حفظ ربط. التقرير الحقيقي يظل خلف المصادقة وإعداد الخادم وموافقة الجرد، ويقتصر على نطاق المصادر المشتركة.
- واجهة المساعد الموجودة: تسجيل صوت بعد الإذن، إيقاف وإلغاء، تحرير التفريغ، وجهة محددة ومراجعة المسودة؛ تبقى غير متاحة عند غياب إعداد المزوّد. أزرار «سجل صوت» و«خطط يومي» تفتح المسار المحمي دون تشغيل الميكروفون أو إرسال طلب تلقائيًا.
- مركز المزامنة يعرض أعداد الحالات الفعلية من سجل المراجعة، النجاح الأخير، الموافقات والتعارضات والاسترداد. لم يتغير منطق التنفيذ؛ معالجة الكتابة غير المؤكدة تأتي من commit حماية المالك السابق.

البيانات اليومية تجريبية في الذاكرة وتُعاد عند تحديث الصفحة؛ إعداد الثيم وحده محلي دائم. اسم المالك الظاهر «إلهام» عرض واجهة، وليس إنشاء حساب. تفضيل ملخص الانتباه في الإعدادات مؤقت ومصرح بذلك. لا إرسال إشعارات خارجية. خدمات AI والتفريغ قد تفرض رسومًا عند إعدادها؛ لم تُفعّل في هذا العمل.

## الخط والتغطية

أكدنا قراءة جميع الملفات المرفقة قبل التعديل؛ النسخ الإحدى عشرة تساوي أربعة ملفات فريدة. نُسخت دون تعديل إلى `app/fonts/` بناءً على طلب المالك. تستضيف `next/font/local` الملفات من أصل التطبيق؛ لا Google Fonts أو خدمة خطوط خارجية.

| NeoSansArabic-Black.ttf | 900 | الحروف الأساسية والتشكيل والأرقام العربية | العنوان الكبير |

| NeoSansArabic-Light.ttf | 300 | الحروف الأساسية والتشكيل والأرقام العربية | النصوص والثانوي |

## مراجعة التصميم

الرموز المركزية في `app/tokens.css`: كحلي #14243D وأحمر #B71C32 وخلفية #F7F5F3 وحدود #E8E5E1 وألوان فئات لطيفة. الطبقة المشتركة `app/premium.css` تتعامل مع الشاشات السابقة والجديدة دون المساس بـ APIs أو تخزين Notion أو أسرار الخادم. توضح `workspace-navigation.tsx` الوجهات المشتركة، وتستخدم صفحات الاكتشاف والمزامنة `PrivateWorkspace` مع بقاء حراس الخادم.

للمراجعة محليًا استخدم إعداد المالك/قاعدة الاختبار الموضح في `single-owner.md`؛ لا تتطلب الاختبارات أي مفتاح خارجي. لا تنفذ scripts الحقيقية للمزامنة أو تفعّل التكاملات لهذه المراجعة.

```sh
npm run typecheck
npm run lint
npm test
npm run build
npm run security:check
MADAR_CHROMIUM_PATH=/usr/bin/chromium npm run test:e2e
```

صور المراجعة من بيانات اصطناعية فقط في `docs/screenshots/premium-*`. الاختبارات الصوتية تستخدم ميكروفون متصفح اختباري واستجابات تفريغ مصطنعة، وليس مزوّدًا حقيقيًا. إعدادات المصادقة وموافقة مزوّد AI وربط Notion واختبار الكتابة المعتمد تحتاج إعدادًا خاصًا منفصلًا؛ لا ادعاء تشغيلها بمجرد نجاح البناء.
