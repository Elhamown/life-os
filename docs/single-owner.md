# MADAR — تطبيق شخصي لمالك واحد

هذه النسخة توسّع التطبيق الحالي على فرع `feature/single-owner-boundaries` المبني على `feature/controlled-notion-sync`. لا دمج أو نشر أو تفعيل تكاملات تلقائيًا.

## الحساب والمصادقة

يوجد حساب ثابت واحد: `owner`. كلمة المرور تُضبط خارج الواجهة باستخدام `MADAR_OWNER_PASSWORD_HASH`؛ لا جدول مستخدمين أو تسجيل عام أو دعوات أو فرق أو استعادة كلمة مرور عامة. يمكن للمالك استخدام جلسات على أجهزته؛ هذا لا ينشئ حسابات إضافية. لا يقبل تسجيل الدخول معرف مستخدم أو دورًا أو اختيار حساب.

تتطلب صفحات `/` و`/discovery` و`/sync` جلسة على الخادم قبل تقديم HTML أو RSC. تتحقق APIs الخاصة من الجلسة قبل أي قراءة خاصة أو اتصال AI/Notion. الاستثناءات اللازمة للدخول هي `/login` و`POST /api/private/login` و`GET /api/private/session` الذي يعيد حالة المصادقة فقط، إضافة إلى الملفات الثابتة غير الحساسة.

الجلسة JWT بموضوع ثابت `owner`، صالحة 30 دقيقة، مرتبطة بإصدار كلمة المرور وبجلسة قابلة للإلغاء في PostgreSQL. تغيير hash كلمة المرور أو مفتاح توقيع الجلسة يبطل الجلسات القديمة. التحديث الحالي يبطل الكوكيز القديمة التي لا تتضمن إصدار المالك، ويلزم تسجيل دخول جديد. لا حذف أو ترحيل بيانات مطلوب. يتحقق حارس الواجهة من الجلسة كل دقيقة وعند العودة للنافذة أو استعادة الصفحة، وينتقل إلى الدخول الكامل عند فقدان المصادقة أو تعذّر التحقق؛ لا تبقى لوحة خاصة قديمة مفتوحة بعد اكتشاف انتهاء الجلسة.

على HTTPS تُستخدم كوكيز `__Host-madar-private` مع `Secure`, `HttpOnly`, `SameSite=Strict`, `Path=/` ودون `Domain`. استثناء HTTP موجود فقط لـ localhost في الاختبارات/التطوير. CSRF محمي بفحص Origin مطابق تمامًا ورفض Origin المفقود/الخارجي وطلبات Fetch Metadata من cross-site أو same-site. كل تغيير يستخدم POST؛ JSON محدود والصوت multipart محدود مع موافقة صريحة. لا يعتمد التفويض على أي دور يرسله المتصفح.

الحدود المستمرة: 5 محاولات دخول/10 دقائق، 20 طلب AI/10 دقائق، 30 طلب sync/10 دقائق. حد الدخول العام يحمي حساب المالك من التخمين لكنه قد يُستنفد؛ راجع حماية الحافة/WAF قبل نشر عام. الخروج يلغي الجلسة ثم يمسح الكوكي؛ عند فشل تأكيد الخروج تعرض الواجهة خطأ بدل الادعاء بنجاحه.

## حدود البيانات

السياسة المركزية في `app/lib/access-policy.ts` تفصل الوزارة، ستاردست، استوديو السلام، والمعلومات الشخصية إلى أربعة أقسام. المالك يستطيع مراجعتها كلها؛ الأقسام حدود بيانات وليست حسابات أو أدوار مستخدمين.

- سياق AI ومسوداته الجديدة محفوظان بمفاتيح منفصلة لكل مساحة، مثل `ai-context:stardust` و`ai-proposals:studio`، مع تشفير AES-GCM مربوط باسم المفتاح. لا يمكن تبديل ciphertext بين المساحات دون فشل التحقق.
- API وواجهة المساعد تعملان على المساحة المختارة فقط. لا يُرسل سياق مساحة أخرى للمزوّد، ولا يُقبل مقترح أو مرجع تخطيط أو قرار اعتماد ينقل السجل إلى مساحة أخرى. اختر المساحة الجديدة وأنشئ طلبًا مستقلًا عند الحاجة.
- تبديل المساحة يمسح النص والسياق والمسودات الظاهرة والموافقات والمحادثة السابقة من الواجهة، ويلغي التسجيل. لا تحذف هذه الخطوة السجلات المخزنة.
- البيانات الداخلية القديمة لا تُرحّل أو تُحذف: تُقرأ فقط بفلترة المساحة، وتُكتب التغييرات المستقبلية في المفتاح المنفصل. سجل جديد بنفس ID يتقدم على نسخته القديمة عند القراءة دون نسخ للسجل إلى مساحة أخرى.
- تقرير الاكتشاف هو مراجعة وصفية صريحة للمالك للمصادر المشتركة. واجهة المزامنة تجمع المسودات المعتمدة للمراجعة فقط، ثم تفرض المصدر والوجهة والحقول المعتمدة لكل سجل. هذه التجميعات لا تصل إلى AI.
- الوزارة والصحة ممنوعتان في سياسة AI على الخادم، بما فيها السياق والصوت والوجهات؛ جميع Notion AI ingestion تبقى معطلة. لا يوجد نظام DLP دلالي يضمن كشف تفاصيل حساسة ألصقها المالك داخل نص مصنف في مجال آخر؛ واجهة الموافقة توضّح عدم إدخالها.

لوحة Today/Spaces ما زالت تستخدم بيانات اصطناعية في الذاكرة. لم يُدخل هذا العمل بيانات الوزارة أو الصحة الحقيقية أو تكاملًا جديدًا معها.

## إصلاح استعادة الكتابة غير المؤكدة

`recover` عملية قراءة جديدة بموافقة المالك، وليست تجديدًا لموافقة الكتابة. يمكنها العمل بعد إعادة الجرد واعتماد النطاق، مع المحافظة على نفس source ID والمجال ووضع test/existing ومعرّفات الحقول القديمة. يجب بقاء المصدر في allowlist الحالية ووجود mapping معتمد في التقرير الحالي. تتحقق القراءة الحية من أنواع ومعرّفات الحقول المطلوبة؛ تغيير حقل غير متعلق لا يمنعها، وتغيير حقول القراءة نفسها يمنعها.

يمكن إيقاف الكتابة عبر `NOTION_SYNC_WRITE_ACK` مع إبقاء التوكن والمصدر المسموح للقراءة المحدودة والاستعادة. سحب التوكن أو المشاركة أو allowlist أو mapping يمنع القراءة أيضًا. تغيير النطاق لا يجيز تنفيذ الموافقة القديمة. الغياب لا يثبت فشل الكتابة، ولا تُعاد كتابة عملية `uncertain` أو `writing`. السجل يحفظ 40 حدثًا عاديًا مع خانة أخيرة محجوزة لنتيجة الاستعادة/التعارض؛ لا يُحذف تاريخ سابق عند امتلائه. بوابة الاختبار القابل للتخلص منه تبقى مطلوبة قبل أي كتابة إلى مصادر حالية؛ لم يُشغّل الاختبار الحي هنا.

## الهوية والخط المرخّص

اللونان ثابتان في design tokens: الكحلي `#14243D` والأحمر `#B71C32`. الثيم الداكن يستخدم درجات نص مقروءة مع الحفاظ على رموز الهوية الأصلية.

أُضيفت ملفات المالك الأصلية الآن إلى `app/fonts/` باستخدام `next/font/local`؛ انظر [تقرير الخط والتصميم](./premium-redesign.md) و[الفحص التفصيلي](./font-audit.json). لم يعد علم `MADAR_NEO_SANS_ENABLED` مطلوبًا. Black وBold وLight تدعم العربية؛ Medium المرفق لاتيني فقط، لذا نصوص العربية تستخدم Light الحقيقي. صور هذا القسم أُخذت قبل إرفاق الخطوط وتبقى توثيقًا لمرحلة حماية المالك السابقة.

## الإعداد والفحوص

اتبع `docs/notion-discovery.md` لإعداد كلمة مرور المالك ومفاتيح الجلسة والتشفير وPostgreSQL الآمن، و`docs/ai-assistant.md` و`docs/notion-sync.md` للتكاملات الاختيارية. لا مفاتيح في المتصفح أو `NEXT_PUBLIC_*` أو المحادثة. لا يُنفّذ البناء أي إنشاء جداول أو migration أو وصول Notion/AI.

```sh
npm run typecheck
npm run lint
npm test
npm run build
npm run security:check
npm audit --omit=dev
MADAR_CHROMIUM_PATH=/usr/bin/chromium npm run test:e2e
```

الفحص الأمني يراجع سطح المسارات، وحماية الصفحات، وفصل الأسرار وSDK عن مكونات وحزم المتصفح، والقيم الفارغة في `.env.example`. اختبارات التنفيذ تتحقق من CSRF والجلسات والمالك الواحد وحدود المساحات ومنع طرق الكتابة في audit mode والاستعادة دون تكرار. هذا ليس إثباتًا لصلاحيات خدمات الإنتاج أو اختبار اختراق شاملًا.

التحقق المحلي لهذه النسخة: 85 اختبار خادم/نموذج و20 اختبار متصفح نجحت، مع نجاح TypeScript وlint وبناء الإنتاج والفحص الأمني. فحص npm لاعتماديات الإنتاج لم يبلغ عن ثغرات معروفة وقت التنفيذ. أضيف workflow للمراجعات يشغّل هذه الفحوص دون أسرار أو نشر؛ تشغيله على GitHub ما زال مرتبطًا بإنشاء PR وإعدادات Actions.

صور ببيانات اصطناعية فقط: [الدخول](./screenshots/single-owner-login.png)، [اليوم](./screenshots/single-owner-today.png)، [الجوال](./screenshots/single-owner-mobile.png). الخط الظاهر هو fallback الحالي، وليس إثباتًا لتوفير Neo Sans المرخّص.

التحقق الحي، وصلاحيات/TLS مخزن الإنتاج، وملفات الخط المرخصة، ومراجعة PR، والدمج والنشر ما زالت إجراءات منفصلة تحتاج موافقتك. لم يتم أي وصول أو تعديل لبيانات Notion الحالية.
